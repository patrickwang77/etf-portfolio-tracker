# ETF Portfolio Tracker

一款針對主動型 ETF (Active ETF) 的實時監測、個人持倉估值以及成分股變動 AI 診斷系統。

目前支援以下四檔 ETF 的完整追蹤：
1. **00997A** (群益美國增長主動式ETF)
2. **00981A** (統一台股增長主動式ETF)
3. **00403A** (統一升級50主動式ETF)
4. **00988A** (統一全球創新主動式ETF)

---

## 🌟 核心功能

*   📊 **淨值與規模監測**：每日自動抓取最新預估淨值、基金規模、發行受益單位數及單日漲跌幅。
*   💼 **成分持股清單**：自動追蹤並儲存每日完整成分股明細與股數（統一投信由官網 DataAsset 解析，群益由 PCF 揭露資訊解析）。
*   🔄 **持股變動比對**：自動比對當日持股與前一日的異動，找出新增持股、刪除持股以及加減碼的權重變化。
*   🧠 **AI 操盤分析（選配）**：串接 Google Gemini API，一鍵針對成分股變動與前十大持股結構進行宏觀與戰術意圖診斷，並給出個人行動建議。
*   💰 **個人資產估值**：可依據各 ETF 分別輸入個人持有單位數（股數），系統會自動計算並繪製個人總部位價值的歷史走勢與單日盈虧變化。
*   📥 **HTML 報告匯出**：支援將 AI 產出的操盤診斷報告一鍵匯出為精美的 HTML 網頁格式。

## 🛠️ 安裝與建置說明

### 1. 系統需求
*   Python 3.8 或以上版本
*   Git

### 2. 複製專案與安裝依賴
```bash
git clone <your-repo-url>
cd etf-portfolio-tracker

# 建議建立虛擬環境
python -m venv venv
venv\Scripts\activate  # Windows

# 安裝所需 Python 套件
pip install -r requirements.txt
```

### 3. 設定環境變數
在專案根目錄下建立一個 `.env` 檔案，填入您的 **Gemini API Key**：
```env
GEMINI_API_KEY=您的_GEMINI_API_KEY
```
*(注意：此檔案已被納入 `.gitignore`，不會被上傳到 Git 倉庫中。)*

## 🚀 使用與執行說明

### 1. 初始化資料庫與同步數據
執行同步腳本來初始化資料庫並抓取最新一天的數據：
```bash
python backend/daily_scrape.py
```
*   **API 流量防護機制**：為了防止每日自動排程爬蟲因 4 檔 ETF 同時調用 AI 分析而導致 Gemini API 流量（TPM/RPM）超限，`daily_scrape.py` 在日常同步時**預設只會進行持股比對，不會調用 Gemini API 生成分析報告**（除非當日持股完全無異動，會直接存入免 API 的靜態提示）。
*   **強制生成報告**：如需在命令列強制生成並存入當日 AI 報告，可加上參數：
    ```bash
    python backend/daily_scrape.py --force-ai
    ```

### 2. 啟動 Web 儀表板
啟動後台 Flask 伺服器：
```bash
python backend/app.py
```
伺服器啟動後，使用瀏覽器打開 `http://localhost:5000` 即可訪問視覺化儀表板。

## 🖥️ 儀表板操作指南

1.  **切換 ETF**：使用左側側邊欄的下拉選單切換要查看的 ETF。
2.  **查看持股與異動**：點擊「成分持股」頁籤，可查看當日全部成分股明細、本次異動詳情（新增、刪除、加減碼）以及資產類別比例。
3.  **手動觸發 AI 分析**：在「AI 最新操盤判斷與行動建議」卡片，點擊「**AI分析**」按鈕，系統將會在後台動態生成當日持股異動的專屬 AI 分析與操盤報告。
4.  **設定個人股數**：在「系統設定」頁籤，可分別輸入您持有的各 ETF 股數，並點擊儲存，首頁的個人資產變化趨勢將會自動更新。
5.  **日誌主控台**：系統設定頁籤提供即時爬蟲日誌主控台，手動同步或強制分析時可在此查看後台進度。
